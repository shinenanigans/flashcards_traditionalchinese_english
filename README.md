# 飲食詞彙 Food Flashcards

Cantonese and Mandarin flashcards for everyday Hong Kong food words.

- `index.html` is the flashcard app. You shouldn't need to edit it.
- `words.js` holds the cards. Edit it to add, change or remove words.

To add a card, open `words.js` on GitHub, click the pencil icon, and add a line like this:

    ["Drinks","檸蜜","ning4 mat6","níng mì","Honey lemon",""],

Then click **Commit changes**. The website updates in about a minute.
